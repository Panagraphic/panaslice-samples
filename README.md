# PanaSlice — Sample Files

Sample Final Cut Pro FCPXML files for testing **PanaSlice**, a macOS
utility that cuts Final Cut Pro clips at regular time intervals.

## Contents

- `PanaSlice_Sample.fcpxmld.zip` — a sample Final Cut Pro project
  bundle (`.fcpxmld`) with three consecutive clips on the primary
  storyline. Use it to test all PanaSlice features.

## How to use with PanaSlice

1. Download and unzip `PanaSlice_Sample.fcpxmld.zip`.
2. Open PanaSlice.
3. Drag the `.fcpxmld` file onto the app (or use the "Apri…" / "Open…"
   button). PanaSlice also accepts plain `.fcpxml` files.
4. Set a cut interval in mm:ss format (e.g. `00:05`).
5. The preview shows how many segments will be generated.
6. Click "Elabora" / "Process" and choose where to save the result.
7. PanaSlice generates a new `.fcpxml` with the cuts applied, ready
   to import back into Final Cut Pro.

Note: the sample references video files that are not included — they
are not needed. PanaSlice works on the FCPXML structure only and does
not require the actual media to function.

These files are provided for Apple App Review and will remain
available for future reviews.
